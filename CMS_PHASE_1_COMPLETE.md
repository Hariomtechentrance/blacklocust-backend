### **API Endpoints:**
- `GET /api/content/hero` - Get hero content
- `POST /api/content/hero` - Save hero content
- `GET /api/content/:type/:name` - Get any content
- `POST /api/content` - Create content
- `PUT /api/content/:id` - Update content
- `DELETE /api/content/:id` - Delete content

## 🚀 **How to Use Hero Section Manager**

### **Step 1: Access the Editor**
1. Login to Admin Panel
2. Click **"Content Management"** in sidebar
3. Click **"Hero Section"** in submenu

### **Step 2: Edit Content**
1. **Change Title** - Edit main hero text
2. **Change Subtitle** - Edit supporting text
3. **Upload Images** - Click upload areas to add images
4. **Edit Buttons** - Change button text, links, styles
5. **Customize Colors** - Use color pickers for styling

### **Step 3: Save Changes**
1. Click **"💾 Save Changes"**
2. Changes are live immediately!
3. No code changes needed!
